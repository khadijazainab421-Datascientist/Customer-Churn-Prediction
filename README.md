# Customer Churn Prediction

## Project Overview

This project uses Machine Learning to predict customer churn and identify customers who are likely to leave a service.

## Dataset

* Telco Customer Churn Dataset
* Total Records: 7,043
* Features: Customer demographics and service usage information
* Target Variable: Churn

## Technologies Used

* Python
* Pandas
* Scikit-Learn
* Matplotlib

## Machine Learning Workflow

1. Data Loading
2. Data Cleaning
3. Data Visualization
4. Feature Encoding
5. Model Training
6. Model Evaluation

## Results

* Model Accuracy: 79.91%
