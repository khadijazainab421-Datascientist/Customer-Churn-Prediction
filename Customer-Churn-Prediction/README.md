# Customer Churn Prediction

## Project Overview

This Machine Learning project predicts whether a customer is likely to churn (leave the company) based on customer behavior and subscription details.

## Dataset

Telco Customer Churn Dataset

* Total Records: 7043
* Features: 20
* Target Variable: Churn

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-Learn
* Logistic Regression

## Exploratory Data Analysis

### Churn Distribution

* Customers Stayed: 5174 (73.46%)
* Customers Churned: 1869 (26.54%)

## Machine Learning Model

Model Used:

* Logistic Regression

Model Accuracy:

* 79.91%

## Visualizations

* Customer Churn Distribution Chart

## Conclusion

The Logistic Regression model achieved approximately 80% accuracy in predicting customer churn, making it a useful baseline model for customer retention analysis.
